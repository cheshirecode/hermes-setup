Autonomous Tool Calling

Executes code, manages terminals, performs web research, and interfaces with Model Context Protocol (MCP) servers locally.

Persistent Memory

Learns project conventions, curates custom skills, and recalls past solutions across sessions without leaking private context.

Strict Security Invariants

All credentials, API keys, and workspace sessions remain on your private machine. No user data is sent to external advertising servers.

Google Drive & Google Sheets Integration

Hermes Agent connects directly to Google Drive and Google Sheets via official OAuth 2.0 and MCP tool standards. This allows the agent to search your reference files, inspect spreadsheets, and analyze documents on your explicit command.

  • Read-Only File Access (drive.readonly): Used only when you ask the agent to search or read reference documents.
  • Spreadsheet Management (spreadsheets): Used to inspect and update sheets per your instructions.
  • Local Processing: File contents are retrieved on-demand directly to your local runtime session and are never sold, transferred to third parties, or used for model training.
  • Revocable Anytime: You can revoke access at any moment via Google Account Permissions.
