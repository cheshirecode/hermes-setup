# Research Summary Skill

## Purpose
Produce compact, high-signal engineering summaries from external documentation, API references, and open-source implementations.

## Guidelines
- Extract verified specifications, supported parameters, and rate limits.
- Exclude marketing fluff; focus on type signatures, error modes, and edge cases.
- Structure output as: Executive Summary, Key Constraints, Code Examples, and Open Questions.
